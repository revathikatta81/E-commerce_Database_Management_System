# E-Commerce Database Management System

## Project Overview
The E-Commerce Database Management System is a SQL-based database project developed using MySQL. It is designed to store, manage, and retrieve information related to customers, product categories, products, orders, and payments.

This project demonstrates database design, SQL queries, CRUD operations, and advanced database concepts.

## Objectives
- Store and manage customer information.
- Organize products into different categories.
- Maintain customer orders and order statuses.
- Track payment methods, amounts, and payment statuses.
- Generate useful business reports using SQL queries.

## Technologies Used
- **Database:** MySQL
- **Query Language:** SQL
- **Database Tool:** MySQL Workbench
- **Database Design:** ER Diagram

## Database Design

The project consists of five main tables:

| Table Name | Description |
|---|---|
| Customers | Stores customer details |
| Categories | Stores product categories |
| Products | Stores product information |
| Orders | Maintains customer order details |
| Payments | Stores payment information |

## Key Features

1. **CRUD Operations:** Insert, retrieve, update, and delete records.
2. **Aggregate Functions:** COUNT(), SUM(), AVG(), MIN(), MAX().
3. **String Functions:** UPPER(), LOWER(), LENGTH(), CONCAT(), SUBSTRING().
4. **Date Functions:** CURDATE(), NOW(), DATEDIFF(), DATE_FORMAT().
5. **SQL Clauses:** WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.
6. **Joins:** INNER JOIN and LEFT JOIN.
7. **Subqueries:** Retrieve records using nested queries.
8. **Views:** Create category-wise sales reports.
9. **TCL Commands:** COMMIT, ROLLBACK, SAVEPOINT.
10. **Stored Procedures:** Retrieve details of a particular order.
11. **Triggers:** Automatically update product stock after inserting an order.

## SQL Concepts Implemented

- DDL – Data Definition Language
- DML – Data Manipulation Language
- DQL – Data Query Language
- DCL – Data Control Language
- TCL – Transaction Control Language
